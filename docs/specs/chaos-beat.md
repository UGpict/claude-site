# spec: CHAOS BEAT（カオス振り子ストップの作り替え）

二重振り子を狙って止めるスコアゲームを、**リズム×カオスの30秒アーケード**に作り替えたもの。
物理エンジン（RK4 二重振り子）はそのまま流用し、ゲームループと採点・演出・音を変えている。

- 対象ページ：`/games/chaos-pendulum/`（作り替え。別ページは作らない）
- 物理：`src/scripts/games/chaos-pendulum.ts` の RK4 二重振り子計算は維持（挙動を変えない）
- 音・通信・計測・保存：エンジンからは分離（onEvent 経由）

> この文書は**現行仕様**だけを書く。廃止した案は末尾「廃止済み仕様」にまとめてあり、現行仕様として扱わないこと。

## 不変条件（変えるときは spec から直す）

1. **30秒固定**：1ゲームは30秒。時間延長ボーナスは導入しない。カウントインは30秒に含めない。
2. **リズム整合（timeScale = 1）**：ターゲットが存在している通常プレイ中は物理の `timeScale = 1` を維持する。
   理由：音の入力拍と未来軌道予測を一致させるため。物理時間の速度を変える仕組み（FEVER 速度・アシスト・難易度別速度）は入れない。
   スローは「叩いた直後（hit → 次の的が出るまでの約0.2秒）」だけ。
3. **共通 beat grid**：BGM の拍頭・cue（タン/ドン）・`target.hitAt`・アプローチリングの収束は、すべて
   `beatTime = transportStart + beatIndex × SPB` の同じ beatIndex で決まる。「BPM が同じ」ではなく「同じ拍の上にある」こと。
4. **判定は距離ベース**：押した瞬間の先端 ↔ 的中心の距離で判定する（タイミングのズレは計測するが判定には使わない）。
5. **物理は不変**：`deriv/rk4/tips` と固定タイムステップ（1/300 秒）は変えない。

## コアループ
- **TAP TO START**：ページを開くと振り子の静止プレビュー＋「CHAOS BEAT / 音を聞いてタイミングを狙え / [TAP TO START] /
  タップ / クリック / Space」のオーバーレイ。ユーザー操作で AudioContext を起こしてから始める（初回の無音・位相ズレを防ぐ）。
- **カウントイン**：開始操作のあと 4 拍（タン・タン・タン・タン → 拍0で GO のドン、画面に 3・2・1）。拍0 が gameTime=0。
- 黄色いターゲット（円）が**1つずつ**出る。「叩く」入力（タップ／クリック／スペース）の瞬間の、
  **先端おもり ↔ ターゲット中心の距離**で判定する。
- **ターゲットはリズムパターンの入力拍に対応する未来軌道点に置く**（リズム×カオスの核）。
  パターン先頭を「次の拍頭」に合わせ、`hitAt = beatTime(次の拍 + hitBeat)`。その時刻の予測軌道位置に的を出す。
  = 音（タン・タン・ドン）でタイミングが分かり、振り子を目で見て微調整すると PERFECT。
- **寿命**：`hitAt + 1.2拍` を過ぎたら見逃し MISS（コンボ切断）→ すぐ次の的。「じっと待つ」を最適戦略にしない。
- **BPM 脈動**：ターゲットは 130 BPM の拍頭で「ドクン」と膨らむ。音が出ない環境でも視覚の脈動は出す。
- 叩いた瞬間 **約0.2秒スロー → 判定表示 → 次のターゲット**。振り子はリセットしない。
- **slowmo 中は入力無効**（`state !== 'playing'` なら無視）。連打で判定が暴れるのを防ぐ。
- 30秒で終了 → スコア＋最大コンボ表示 → **即リトライ**（[もう一回]／Space／Enter）。
  リトライも初回と同じ開始経路（transport 張り直し → カウントイン → 開始）を通る。

## 判定（距離ベース）
内部の 0〜100 点の距離採点は分析用に残すが、**得点になるのは GOOD 以上だけ**。

| 判定 | 条件（的中心からの距離 d、的半径 R） | 得点 | 表示 |
| --- | --- | --- | --- |
| PERFECT | d ≤ 0.35R | 90〜100 × 倍率 | 画面フラッシュ＋強SE |
| GREAT | d ≤ 0.7R | 70〜90 × 倍率 | 光る＋SE |
| GOOD | d ≤ R | 40〜70 × 倍率 | 軽いSE |
| NEAR MISS | R < d ≤ 1.25R | **0点** | 「◯秒早い/遅い！」（`gameTime − hitAt`） |
| MISS | d > 1.25R、または寿命切れ | **0点** | 「MISS」／寿命切れは「見逃し…」 |

- `NEAR MISS / MISS は 0 点`（部分点は連打ゲー化するため）。

## コンボ
- GOOD 以上で +1、NEAR MISS / MISS（寿命切れ含む）で 0。
- 倍率：`3 → ×1.2` / `5 → ×1.5` / `10 → ×2.0`。適用順は `判定 → コンボ+1 → 倍率再計算 → 今回分に加算`。
- 最大コンボをゲーム通して記録（ランキング指標）。

## CHAOS FEVER
- PERFECT **3連続**で発火、5秒間：**得点 ×2**、BGM に lead 層、画面演出（ピンクの縁の明滅・FEVER 表示）。
- MISS / NEAR で解除。**物理の速度は変えない**（不変条件2）。

## 難易度
差は **的の大きさ（targetR）・初期条件（初期角レンジ）・的を置く距離** で作る。物理の速度は全段同じ。
譜面パターンの複雑さは序盤やさしめ（hits<6 は A/B のみ）→ 以降 C/D を混ぜる（全難易度共通）。

| 難易度 | targetR | 初期角 θ1 / θ2 |
| --- | --- | --- |
| 易しい | 0.55 | 1.9–3.0 / 1.6–3.1 |
| 普通 | 0.34 | 1.9–3.0 / 1.5–3.1 |
| 難しい | 0.20 | 1.9–3.0 / 1.4–3.1 |
| 鬼 | 0.13 | 2.2–3.3 / 2.0–3.3 |

## 音（Web Audio API のみ・外部音源なし）
- **BPM 130**（`beat-grid.ts` の1か所で定義）。
- **リズム予告（cue）**：各ターゲットに「タン・タン・ドン」。`RHYTHM_PATTERNS`（A〜D）をデータ駆動で持ち、
  譜面シーケンス（`RHYTHM_SEQUENCES`）で順番に消化。直前と同じシーケンスは避ける。
- **持続BGM（実装済み）**：ゲーム中ずっと拍に同期して鳴るループ。コンボで層が増える。

  | 状態 | 鳴る層 |
  | --- | --- |
  | combo 0–2 | drum |
  | combo 3–4 | + bass |
  | combo 5–9 | + hihat |
  | combo 10+ | + melody |
  | FEVER | + lead |

  MISS / NEAR で combo=0 になったら、**次の拍から drum のみ**。層の切替は拍頭に同期。
- **役割分担**：`judgment()` = 判定フィードバック SE のみ ／ BGM スケジューラ = 曲の層。
- **cue 最優先**：BGM は cue より明確に小さい（BGM マスター 0.5、ドンの音量はキックより大きい）。
  さらに accent（ドン）の −80ms〜+120ms だけ BGM を約 −5dB ダッキングする。

## 計測（GA4・既存 analytics 経由）
- `hit`：`kind / pts / score / combo / comboMult / maxCombo / distancePx / nearMissPx / timingOffsetMs / expired`。
- `game_over`：`score / maxCombo / hits / perfectCount / greatCount / goodCount / nearCount / missCount / expiredCount /
  averageAbsTimingOffsetMs / averageTimingOffsetMs / difficulty`。
- `game_start` / `game_retry`（difficulty 付き）：`game_retry ÷ game_over` で終了後の再プレイ率を見る。
- **判定は変えない**。「音にぴったり合わせても PERFECT にならない」がデータで多いと分かった場合のみ、
  将来 timingOffset を補助条件にする（現時点では実装しない）。

## ランキング
- 今日／今週／歴代 × 難易度別タブ。指標は **スコア**（副キー：最大コンボ）。

## 廃止済み仕様（Deprecated — 現行仕様ではない）
以下は過去の案・実装で、**すべて廃止**。コードにも docs の現行節にも戻さないこと。
- **Magnet Assist**（的付近でスローにする易しさ補助）：timeScale ≠ 1 になり音とズレるため廃止。
- **難易度ごとの timeScale 変更／鬼の速度UP**：同上。難易度差は targetR・初期条件・譜面で作る。
- **FEVER 中の速度 ×1.3**：同上。FEVER は得点×2＋音と演出のみ。
- **青ターゲットの +2秒（時間延長）**：30秒固定尺を守るため不採用。
- **「曲レイヤー未実装」**という記述：持続BGMは実装済み。
- **判定SEに bass/hihat/melody の一発音を足す旧方式**：持続BGMの層に置き換え済み。
- **的の固定寿命 3秒／ランダムな未来点への配置**：入力拍（hitAt）基準の配置と `hitAt + 1.2拍` 寿命に置き換え済み。
- **BGM を `currentTime + 0.1` から別クロックで開始する方式**：共通 transport に置き換え済み。
