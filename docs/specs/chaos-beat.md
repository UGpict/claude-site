# spec: CHAOS BEAT（カオス振り子ストップの作り替え）

現状の「二重振り子を狙って止める」スコアゲームを、**リズム×カオスの30秒アーケード**に作り替える。
物理エンジン（RK4 二重振り子）はそのまま流用し、ゲームループと採点・演出・音を変える。

- 対象ページ：`/games/chaos-pendulum/`（作り替え。別ページは作らない）
- 物理：`src/scripts/games/chaos-pendulum.ts` の RK4 二重振り子計算は維持（挙動を変えない）
- 音・通信・計測・保存：従来どおりエンジンからは分離（onEvent 経由）

## 何を作るか（あるべき仕様）

### コアループ
- 1ゲーム **30秒**（固定尺。この固定尺がリトライテンポの強み。時間延長ボーナスは入れない）。
  振り子は最初から最後まで**止まらず動き続ける**。
- 黄色いターゲット（円）が**1つずつ**出る。プレイヤーが「叩く」入力（クリック／タップ／スペース）をした瞬間の、
  **先端おもり ↔ ターゲット中心の距離**で判定する。
- **ターゲットは「これから先端が通る軌道上」かつ「次の拍で通過する位置」に置く**（リズム×カオスの核）。
  現在状態から近い将来（~2秒）を予測し、**次の拍＋1〜3拍先**に先端が来る軌道点に出す。
  = プレイヤーは「ドン…ドン…今！」で拍に乗って押せる。ランダム位置だと通らず理不尽なので不可。
- **ターゲットには寿命がある**：予測到達時刻＋猶予（約0.9秒）で消滅 → その的は **MISS**（コンボ切断）→ すぐ次の的。
  「完璧な位置までじっと待つ」を最適戦略にしないための肝。
- **BPM 脈動（Phase 1 から必須）**：ターゲットは 120〜140 BPM で「ドクン」と膨らむ（音楽レイヤーは後でも、
  拍の脈動だけは最初から）。これが無いと「30秒クリックゲー」のままで「リズム×カオス」にならない。
  音が出せない環境でも Canvas 側の視覚脈動だけは出す。
- 叩いた瞬間 **約0.2秒スロー（timeScale を落とす）→ 判定表示 → すぐ次のターゲット出現**。
  振り子はリセットしない（動き続けたまま次へ）。
- **slowmo 中は入力を無効化**（`state !== 'playing'` なら無視）。スマホのダブルタップ／スペース連打で判定が暴れるのを防ぐ。
- 30秒経過で終了 → 大きくスコア＋最大コンボを表示 → **即リトライ**（[もう一回]）。
- 1ゲームの試行回数が自然に 15〜30 回程度になり「もう一回で最高コンボ更新できそう」が成立する。

### 判定（距離ベース）
内部は従来の 0〜100 点の距離採点を**分析用として残す**が、**得点になるのは GOOD 以上だけ**。

| 判定 | 条件（的中心からの距離 d、的半径 R 基準） | 得点 | 演出 |
| --- | --- | --- | --- |
| PERFECT | d ≤ 0.35R | 加算 | 画面フラッシュ＋強SE＋（振動 API あれば）バイブ |
| GREAT | d ≤ 0.7R | 加算 | 光る＋気持ちいいSE |
| GOOD | d ≤ R | 加算 | 軽いSE |
| NEAR MISS | R < d ≤ 1.25R | **0点** | 「あと ◯px！」を強調（惜しさの可視化） |
| MISS | d > 1.25R、または寿命切れ | **0点** | コンボ切断 |

- **重要**：`NEAR MISS / MISS は 0 点`。部分点を与えると「スペース連打で偶然 GOOD を量産」する連打ゲーになるため。
  得点対象は PERFECT / GREAT / GOOD のみ。
- **中央を狙う意味を強くするため点差を広げる**（内部100点満点は分析用に維持）：
  PERFECT=90〜100 / GREAT=70〜90 / GOOD=40〜70。
- **表示の出し分け**：NEAR MISS は距離ではなく**タイミングのズレ**「◯秒早い/遅い！」を出す（軌道予測から最接近時刻を求める）。
  MISS は「MISS」のみ（遠くで押して「あと187px」等の的外れな“惜しい”は出さない）。

### コンボ
- GOOD 以上でコンボ +1、NEAR MISS / MISS（寿命切れ含む）で 0 に戻す。
- 倍率：`3 combo → ×1.2` / `5 → ×1.5` / `10 → ×2.0`（間は据え置き、達したら昇格）。
- **適用順（今回のヒットに効かせる＝アーケード的に気持ちいい）**：
  `判定 → GOOD以上ならコンボ+1 → 倍率を再計算 → score += round(基本点 × 倍率)`。
  例：2combo で PERFECT → 3combo に上がってから ×1.2 を今回分に適用。
- **最大コンボ**をゲーム通して記録する（ランキング指標に使う）。

### CHAOS FEVER
- PERFECT を**3連続**で発火。一定時間（例 5秒）：
  - 振り子速度 **×1.3**、得点 **×2**、音楽が層を増す、画面演出強化。
- FEVER 中に MISS で解除。

### 難易度（カオスは全段維持。差は的サイズ＋補助）
| 難易度 | 的サイズ | 補助 |
| --- | --- | --- |
| 易しい | 大 | Magnet Assist：的付近（例 半径80px以内）で timeScale≈0.65 のスロー |
| 普通 | 中 | 弱スロー |
| 難しい | 小 | なし |
| 鬼 | 小 | なし＋振り子速度UP |

### 音（Web Audio API のみ・外部音源なし）
- BPM 120〜150 のビート。ターゲットが**拍に合わせて脈動**する。
- **上達＝曲が完成していく**：コンボでレイヤーが増える。
  - 開始：ドラムのみ → 3combo：ベース追加 → 5combo：シンセ → 10combo：メロディ。
- 判定ごとのSE（PERFECT/GREAT/GOOD/MISS）は従来の合成音を強化して流用。

### ランキング
- 器（今日／今週／歴代・難易度別タブ）は現状を流用。
- 指標を **スコア** と **最大コンボ** に。行に最大コンボ列を足すか、並べ替えの副キーに使う。
- スコアは30秒の合計（従来の 0〜500 より大きくなりうる）。

## やらないこと（非目標）
- 動画キャプチャ機能（Xへの投稿は OS 録画に委ねる）。
- 外部API・課金・サーバー音源。音は全部 Web Audio 合成。
- サーバー権威の本格アンチチート（従来どおり最低限の整合チェックのみ）。
- 別ゲームページの新設（既存を作り替える）。

## 段階（フェーズ）
- **Phase 1（コアループ）**：30秒連続・1的ずつ・**的3秒寿命→MISS**・**BPM脈動（視覚）**・
  PERFECT/GREAT/GOOD で加点／NEAR MISS・MISS は 0点・0.2秒スロー→即次・**slowmo中は入力ロック**・
  コンボ＋倍率（今回のヒットに適用）・「あとNpx」・判定SE＋フラッシュ・スコア＋最大コンボ表示・即リトライ・ランキング接続。
- **Phase 2（気持ちよさ）**：CHAOS FEVER・Magnet Assist（難易度別）・BPM に**音**を乗せる（拍のクリック音）。
- **Phase 3（アーケード化）**：コンボで曲が層を増す・動く的・ボーナス的。
  - ボーナス的：赤＝スコア3倍、**青＝「次の3秒スコア×2」または「コンボ保護1回」**（時間延長にはしない。30秒固定尺を守る）、虹＝FEVER。
