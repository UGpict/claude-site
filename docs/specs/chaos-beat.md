# spec: CHAOS BEAT（カオス振り子ストップの作り替え）

現状の「二重振り子を狙って止める」スコアゲームを、**リズム×カオスの30秒アーケード**に作り替える。
物理エンジン（RK4 二重振り子）はそのまま流用し、ゲームループと採点・演出・音を変える。

- 対象ページ：`/games/chaos-pendulum/`（作り替え。別ページは作らない）
- 物理：`src/scripts/games/chaos-pendulum.ts` の RK4 二重振り子計算は維持（挙動を変えない）
- 音・通信・計測・保存：従来どおりエンジンからは分離（onEvent 経由）

## 何を作るか（あるべき仕様）

### コアループ
- 1ゲーム **30秒**。振り子は最初から最後まで**止まらず動き続ける**。
- 黄色いターゲット（円）が**1つずつ**出る。プレイヤーが「叩く」入力（クリック／タップ／スペース）をした瞬間の、
  **先端おもり ↔ ターゲット中心の距離**で判定する。
- 叩いた瞬間 **約0.2秒スロー（timeScale を落とす）→ 判定表示 → すぐ次のターゲット出現**。
  振り子はリセットしない（動き続けたまま次へ）。
- 30秒経過で終了 → 大きくスコア＋最大コンボを表示 → **即リトライ**（[もう一回]）。

### 判定（距離ベース）
内部は従来の 0〜100 点の距離採点を残す。表示は段階ラベルにする。

| 判定 | 条件（的中心からの距離 d、的半径 R 基準） | 演出 |
| --- | --- | --- |
| PERFECT | d ≤ 0.35R | 画面フラッシュ＋強SE＋（振動 API あれば）バイブ |
| GREAT | d ≤ 0.7R | 光る＋気持ちいいSE |
| GOOD | d ≤ R | 軽いSE |
| MISS | d > R かつ 惜しくない | 「惜しい！」は出さない |
| NEAR MISS | d が R をわずかに超える（R < d ≤ 1.25R） | 「あと Npx！」を強調 |

- MISS/NEAR MISS 時は**惜しさを可視化**する：`あと ◯px！`（px は画面スケール換算）。
  可能なら `◯◯秒早かった/遅かった` も出す（次の最接近タイミングとの差）。

### コンボ
- GOOD 以上でコンボ +1、MISS で 0 に戻す。
- 倍率：`3 combo → ×1.2` / `5 → ×1.5` / `10 → ×2.0`（間は据え置き、達したら昇格）。
- スコア加算 = `判定の基本点(0〜100) × 現在のコンボ倍率`。
- **最大コンボ**をゲーム通して記録する（ランキング指標に使う）。

### CHAOS FEVER
- PERFECT を**3連続**で発火。一定時間（例 5秒）：
  - 振り子速度 **×1.3**、得点 **×2**、音楽が層を増す、画面演出強化。
- FEVER 中に MISS で解除。

### 難易度（カオスは全段維持。差は的サイズ＋補助）
| 難易度 | 的サイズ | 補助 |
| --- | --- | --- |
| 易しい | 大 | Magnet Assist：的付近（例 半径80px以内）で timeScale≈0.65 のスロー |
| 普通 | 中 | 弱スロー |
| 難しい | 小 | なし |
| 鬼 | 小 | なし＋振り子速度UP |

### 音（Web Audio API のみ・外部音源なし）
- BPM 120〜150 のビート。ターゲットが**拍に合わせて脈動**する。
- **上達＝曲が完成していく**：コンボでレイヤーが増える。
  - 開始：ドラムのみ → 3combo：ベース追加 → 5combo：シンセ → 10combo：メロディ。
- 判定ごとのSE（PERFECT/GREAT/GOOD/MISS）は従来の合成音を強化して流用。

### ランキング
- 器（今日／今週／歴代・難易度別タブ）は現状を流用。
- 指標を **スコア** と **最大コンボ** に。行に最大コンボ列を足すか、並べ替えの副キーに使う。
- スコアは30秒の合計（従来の 0〜500 より大きくなりうる）。

## やらないこと（非目標）
- 動画キャプチャ機能（Xへの投稿は OS 録画に委ねる）。
- 外部API・課金・サーバー音源。音は全部 Web Audio 合成。
- サーバー権威の本格アンチチート（従来どおり最低限の整合チェックのみ）。
- 別ゲームページの新設（既存を作り替える）。

## 段階（フェーズ）
- **Phase 1（コアループ）**：30秒連続・1的ずつ・PERFECT/GREAT/GOOD/MISS/NEAR MISS・0.2秒スロー→即次・コンボ＋倍率・「あとNpx」・判定SE＋フラッシュ・スコア＋最大コンボ表示・即リトライ・ランキング接続。
- **Phase 2（気持ちよさ）**：CHAOS FEVER・Magnet Assist（難易度別）・BPM で的が脈動。
- **Phase 3（アーケード化）**：コンボで曲が層を増す・動く的・ボーナス的（赤3倍/青+2秒/虹FEVER）。

## 未確定・要判断（実装中に詰める）
- タイトルを「CHAOS BEAT」に変えるか（現「カオス振り子ストップ」）。→ Phase 1 では内部だけ切替、表記変更は後で決める。
- ランキングの並び：スコア主／最大コンボ主／両方タブ。→ Phase 1 はスコア主・最大コンボ併記で開始。
- 既存スコア（5ラウンド時代）は指標が別物なので、切替時に D1 をクリアする。
