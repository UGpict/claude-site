「Claude を使ってみたいけれど、お金がかかるのかな」。
そう思って、一歩ふみ出せずにいる人は多いはずです。

結論から言うと、<mark>Claude は無料でも始められます。</mark>
そのうえで、もっと使いたくなったら有料の道が用意されている、という作りです。

この記事では、Claude の 4 つの入り口 —— 無料・Pro・Max・API の違いと、自分に合った選び方を整理します。
金額そのものは変わりやすいので、ここでは「どれが誰向けか」という地図をお渡しします。

![Claudeの4つの入り口。無料・Pro・Max・API。それぞれ向いている人がちがう。](/diagrams/claude-plans.svg)

## まずは「無料」で十分

いちばん最初の入り口は、無料プランです。
ウェブ版（ブラウザやアプリ）から、アカウントを作るだけで使い始められます。

無料でも、文章の作成や要約、調べものの相談、翻訳など、基本的なことはひと通りできます。
ただし、<mark>1 日に使える量には上限があります。</mark>
たくさん続けて話しかけると、「今日はここまで」と一時的に止まることがあります。

とはいえ、最初はこれで十分です。
まず無料で触ってみて、自分の生活にどう役立つかを確かめる。
その段階では、お金の心配はいりません。

## 毎日使うなら「Pro」

無料で使ってみて、「これは便利だ、もっと使いたい」となったら。
次に見えてくるのが **Pro（プロ）** という有料プランです。

Pro は、月ぎめの定額で使うプランです。
無料版とくらべて、使える量がぐっと増えます。
上限にぶつかって止まることが減り、より賢いモデルも選べるようになります。

仕事や勉強で毎日のように使う人、
無料の上限がもどかしくなってきた人は、まず Pro を検討するのが王道です。

## とことん使うなら「Max」

Pro でも足りない、という段階になると **Max（マックス）** が候補になります。

Max は、Pro よりさらに使える量の上限が広いプランです。
長い資料をいくつも読ませたり、[Claude Code](/blog/claude-code-tsukaikata/) で一日じゅう開発作業を任せたり。
そんな「重い使い方」をする人のためのプランです。

料金は Pro より高めになります。
ですから、いきなり Max を選ぶ必要はありません。
<mark>まず Pro で使ってみて、上限が気になり始めてから Max を考える。</mark>
この順番で失敗しません。

## 自分の道具に組み込むなら「API」

ここまでの 3 つは、Claude と直接おしゃべりするためのプランでした。
4 つめの **API（エーピーアイ）** だけは、少し性格がちがいます。

API は、自分のアプリやサービスの中に Claude を組み込むための、開発者向けの入り口です。
支払い方も定額ではなく、「使った分だけ払う」しくみになっています。

自分でツールを作りたい人向けなので、多くの人には最初は関係ありません。
「そういう入り口もあるんだな」と、頭のすみに置いておけば十分です。
API について、くわしくは [Claude とは何か](/blog/claude-toha-nanika/) でも触れています。

## 選び方は、たったこれだけ

プランが 4 つあると聞くと身構えますが、選び方はシンプルです。

| こんな人 | 向いている入り口 |
| --- | --- |
| まず試したい | **無料** |
| 毎日ふつうに使う | **Pro** |
| 重い作業をたくさんする | **Max** |
| 自分のツールに組み込む | **API** |

迷ったら、<mark>無料 → Pro → Max の順に、必要になってから上げていけば大丈夫です。</mark>
最初から高いプランを選ぶ必要はありません。

## よくある疑問

**無料のままでも使い続けられますか？**
はい。無料プランに期限はありません。
1 日の上限の範囲でなら、ずっと無料で使えます。

**プランはあとから変えられますか？**
変えられます。
使ってみて足りなければ上げ、使わなくなれば下げる、で構いません。
「まず安いほうから」で気楽に始めてください。

**Claude Code を使うにもお金がかかりますか？**
Claude Code は、Pro や Max のプラン、または API があれば使えます。
くわしい対応関係や金額は変わりやすいので、公式サイトで確認するのが確実です。

**API の料金が変わるって聞きましたが？**
はい。API で使えるモデルの一つ「Claude Sonnet 5」の割引価格が、2026 年 8 月 31 日で終了します。
9 月 1 日からは通常価格になります。
このように<mark>料金は折々で変わる</mark>ので、API を使う人は、最新の価格を公式サイトで確認する習慣をつけておくと安心です。

## まとめ

Claude の入り口は、無料・Pro・Max・API の 4 つ。
けれど、覚えることは多くありません。
<mark>まず無料で試して、必要になったら一段ずつ上げる。</mark>
これだけ押さえておけば十分です。

具体的な金額は移り変わっていくので、最新の料金は公式サイトで確かめてください。
大事なのは、金額の暗記ではなく「自分はどの入り口から入ればいいか」を知っておくこと。

お金の不安で立ち止まっているなら、まずは無料プランから。
一度使ってみれば、自分にとっての「ちょうどいい入り口」が、自然と見えてきます。
