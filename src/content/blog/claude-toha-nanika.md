「Claude（クロード）って最近よく聞くけれど、結局なに？」

ニュースを開いても、まわりの会話でも、気づけば AI の話ばかり。
名前は知っていても、ほかの AI と何が違うのか、何ができるのかは、意外とはっきりしないものですよね。
でも、心配はいりません。
この記事では、その「結局なに？」に、ひとつずつ順番に答えていきます。
専門用語はできるだけかみくだくので、まったくの初心者でも、置いていかれる心配なく読み進められます。

## Claude はひとことで言うと

**Claude** は、アメリカの Anthropic（アンソロピック）という会社が作っている AI アシスタントです。
チャットで質問すると、自然な文章で答えてくれます。
<mark>文章の作成や要約、調べものの整理、翻訳、そしてプログラミングまで、幅広い作業を手伝ってくれます。</mark>

裏側で動いているのは、**大規模言語モデル**（LLM: Large Language Model）という技術です。
ものすごい量の文章を学習し、「次に来そうな言葉」を予測することで、人と会話しているかのような受け答えを実現しています。

仕組みを知らなくても使えます。
ただ、一つだけ覚えておくと得をする事実があります。
Claude は言葉の意味を人間のように理解しているわけではなく、確率的にもっともらしい言葉を選んでいる、ということです。
この性質は、あとで出てくる「苦手なこと」に関わってきます。

## モデルには「種類」がある

Claude には、用途に応じた複数のモデルがあります。
名前は少しややこしいのですが、大きく 3 つのグレードで捉えると分かりやすくなります。

![Claude のモデル 3 グレード。Opus は最も賢い、Sonnet はバランス型、Haiku は最速で低コスト。](/diagrams/models.svg)

| グレード | 性格 | 向いている用途 |
| --- | --- | --- |
| **Opus**（オーパス） | 最も賢く、じっくり考える | 難しい調査、長い作業、複雑なコード |
| **Sonnet**（ソネット） | 速さと賢さのバランス型 | 日常のほとんどの作業 |
| **Haiku**（ハイク） | 最速で低コスト | 軽い分類や短い返答 |

さらに世代（バージョン）があり、新しいものほど賢くなります。
執筆時点では、最上位の「Claude 5」系や Opus 4.8 などが提供されています。
細かいバージョン名は入れ替わっていくので、最初から覚える必要はありません。
<mark>「難しい仕事は Opus、ふだん使いは Sonnet、軽い処理は Haiku」。</mark>
まずは、この感覚だけで十分です。

## どこで使えるのか

Claude に触れる入り口は、大きく 3 つあります。

- **ウェブ / デスクトップアプリ**:ブラウザやアプリからチャットで使う、いちばん手軽な方法。まずはここから。
- **API**:自分のアプリやサービスに Claude を組み込むための、開発者向けの入り口。
- **Claude Code**:ターミナル（黒い画面）やエディタから、開発作業そのものを任せられる AI エージェント。

三つめの Claude Code は、この入門シリーズでいちばん紹介したい入り口です。
くわしくは [Claude Code の使い方](/blog/claude-code-tsukaikata/) にゆずります。

## Claude・Gemini・Codex — 三つの違い

はじめての人がまず気になるのが、他社の AI との違いでしょう。
土台はどれもよく似た大規模言語モデルで、できることの大枠は同じです。
ただ、<mark>作っている会社ごとに「得意分野の色」がちがいます。</mark>
代表的な三つ、Claude・Gemini・Codex を見くらべてみましょう。

![ClaudeとGeminiとCodexの得意分野くらべ。Claudeは文章とコードの質、GeminiはマルチモーダルとGoogle連携、Codexはコード作業の自動化。](/diagrams/ai-compare.svg)

| AI | 作っている会社 | とくに得意なこと | 弱み・注意点 |
| --- | --- | --- | --- |
| **Claude** | Anthropic | 長い文章の読み書き、落ち着いた丁寧な受け答え、質の高いコード | 最新のできごとには弱い。無料で使える量は控えめ |
| **Gemini** | Google | 画像・音声・動画もまとめて扱える。Google 検索やドキュメントとの連携 | 答えが当たり障りなくなることも。Google 前提の設計 |
| **Codex** | OpenAI | プログラミングの自動化。速さと、作業をどんどん任せられる手軽さ | コード寄りの道具。ふだんの雑談や文章づくりは ChatGPT の役目 |

**Claude（この記事の主役）**
文章とコードの「質」で評価されることが多い AI です。
長い資料を読ませても筋を見失いにくく、受け答えの口調も落ち着いています。
込み入ったプログラムの修正でも、ていねいで実用的な答えを返すと言われます。

**Gemini（グーグル製）**
最大の持ち味は、文字だけでなく画像・音声・動画もそのまま理解できることです。
とても長い資料を一度に読み込めて、Google 検索や Gmail、ドキュメントとも自然につながります。
ふだん Google のサービスをよく使う人ほど、なじみやすいでしょう。

**Codex（オープンエーアイ製）**
ChatGPT を作っている OpenAI の、プログラミングに特化した道具です。
「この機能を作って」と頼むと、実際の作業をどんどん自分で進めてくれる手軽さと速さが売りです。
ただし専門は開発。日常の相談ごとは、同じ会社の ChatGPT のほうが向いています。

性能はどれも日進月歩で、優劣は用途や好みで変わります。
最初から比較に悩む必要はありません。
<mark>まず一つ触ってみて、しっくりくるものを選べば十分です。</mark>
ChatGPT との違いや選び方は [Claude と ChatGPT・Gemini はどう違う？](/blog/claude-chatgpt-hikaku/) でくわしく比べています。

## 無料で使えるの？

結論から言うと、無料でも始められます。
お金がかかるのでは、と身構えなくて大丈夫です。
ウェブ版には無料で試せる範囲があるので、まずはここで気軽に雰囲気をつかんでみてください。

そのうえで、もっと賢いモデルを使いたい、たくさん使いたい、という段階になると有料プランや API の利用が視野に入ります。
料金体系は変わりやすいので、具体的な金額は公式サイトで確認してください。
無料・Pro・Max・API のどれを選べばいいかは、[料金プラン入門](/blog/claude-ryokin-plan/) にまとめました。
「まずは無料で試して、必要になったら考える」。
この順番で困ることはありません。

## 何が得意で、何が苦手か

![Claudeの得意と苦手。得意は長い文章の要約・下書き・翻訳・コードの説明。苦手は最新のできごとと、事実をもっともらしく間違えること（ハルシネーション）。](/diagrams/claude-tokui-nigate.svg)

得意なのは、言葉を扱う作業です。
長い文章を読んで要点をまとめる、下書きを書く、コードを説明する。
このあたりは、人が読むより速く、しかも正確にこなします。

苦手なこともあります。
まず、最新のできごとは学習した時点までしか知りません。
そして、さきほど触れた「確率的に言葉を選ぶ」性質のせいで、事実をもっともらしく間違えることがあります。
いわゆるハルシネーション（幻覚）です。

<mark>だから、数字や固有名詞、大事な判断は鵜呑みにせず、自分でも確かめる。</mark>
Claude と上手に付き合うコツは、たったこれだけです。

## よくある疑問

**Q. Claude は無料で使えますか？**
はい。ウェブ版に無料で試せる範囲があります。たくさん・賢く使いたくなったら有料プランや API を。金額は公式サイトで確認を。

**Q. モデルはどう選べばいいですか？**
難しい仕事は Opus、ふだん使いは Sonnet、軽い処理は Haiku。バージョン名は覚えなくて大丈夫です。

**Q. ChatGPT や Gemini と何が違いますか？**
土台は似ていますが得意の色が違います。Claude は長文と丁寧な受け答え、質の高いコードが得意。まず一つ触って選べば十分です。

## まずやってみよう

いちばんの近道は、一度チャットで話しかけてみることです。
たとえば、こんな依頼から始めてみてください。

- 「AI について、小学生にもわかるように 3 行で説明して」
- 「次の文章を、要点だけ箇条書きにして」
- 「週末の献立を、買い物リストつきで提案して」

肩の力を抜いた依頼で十分です。
何度かやりとりするうちに、得意と不得意の輪郭が自然につかめてきます。

「AI に開発作業を丸ごと手伝ってもらう」とは、具体的にどういうことなのか。
実際の使い方を見ていきましょう。
