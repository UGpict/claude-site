「Claude（クロード）って最近よく聞くけど、結局なに？」という人のための最初の 1 記事です。
専門用語はできるだけかみくだいて説明します。

## Claude はひとことで言うと

Claude は、アメリカの **Anthropic（アンソロピック）** という会社が作っている **AI アシスタント**です。
チャットで質問すると自然な文章で答えてくれる、いわゆる「対話型 AI」の一つで、
文章の作成・要約、調べものの整理、翻訳、そしてプログラミングまで、幅広い作業を手伝ってくれます。

裏側では **大規模言語モデル（LLM: Large Language Model）** という技術が動いています。
ものすごく大量の文章を学習して、「次に来そうな言葉」を予測することで、
まるで人と会話しているかのような受け答えを実現しています。仕組みを知らなくても使えますが、
「本当に理解しているわけではなく、確率的に自然な言葉を選んでいる」という点は、
付き合ううえで頭の片隅に置いておくとよいでしょう。

## モデルには「種類」がある

Claude には用途に応じた複数のモデルがあります。名前が少しややこしいのですが、
大きく **3 つのグレード** で覚えると分かりやすいです。

| グレード | 性格 | 向いている用途 |
| --- | --- | --- |
| **Opus（オーパス）** | 最も賢い・じっくり考える | 難しい調査、長い作業、複雑なコード |
| **Sonnet（ソネット）** | バランス型・速さと賢さの両立 | 日常のほとんどの作業 |
| **Haiku（ハイク）** | 最速・低コスト | 軽い分類や短い返答 |

さらに世代（バージョン）があり、新しいものほど賢くなります。
執筆時点では、最上位の「Claude 5」系や Opus 4.8 などが提供されています。
細かいバージョン名は入れ替わっていくので、最初は
「**むずかしい仕事は Opus、ふだん使いは Sonnet、軽い処理は Haiku**」という感覚で十分です。

## どこで使えるの？

Claude に触れる入り口はいくつかあります。

- **ウェブ / デスクトップアプリ**：ブラウザやアプリからチャットで使う、いちばん手軽な方法。まずはここから。
- **API**：自分のアプリやサービスに Claude を組み込むための開発者向けの入り口。
- **Claude Code**：ターミナル（コマンドライン）や、VS Code などのエディタから、
  開発作業そのものを任せられる「AI エージェント」。これは次の記事でくわしく紹介します。

## 何が得意で、何が苦手か

得意なことは、**言葉を扱う作業全般**です。長い文章を読んで要点をまとめる、
下書きを書く、コードを説明する、といった仕事はとても速く正確にこなします。

一方で苦手なこともあります。**最新のできごと**は学習した時点までしか知りませんし、
**事実をもっともらしく間違える**ことがあります（いわゆる「ハルシネーション」）。
数字や固有名詞、重要な判断は、鵜呑みにせず自分でも確認する——これが上手な付き合い方です。

## まずやってみよう

いちばんの近道は、とにかく一度チャットで話しかけてみることです。
「〇〇について小学生にもわかるように説明して」「この文章を 3 行に要約して」など、
気軽な依頼から始めると、得意・不得意の感覚がつかめてきます。

次の記事では、開発者に人気の **Claude Code** を取り上げます。
「AI に開発作業を丸ごと手伝ってもらう」とはどういうことか、具体的に見ていきましょう。
