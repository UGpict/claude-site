「Claude にお願いしたいことはあるのに、一つ頼むたびに、次の指示をこちらが考えないといけない」。
そんな手間を感じたことはないでしょうか。

これまでの AI は、基本は一問一答でした。
「これを調べて」「じゃあ次はこれ」と、次の一手をいつもあなたが渡す必要があった。
その関係が変わりつつあります。

いま話題の **AI エージェント** は、ひとことで言えば <mark>目標を渡すと、自分で段取りを組んで最後までやり切る AI</mark> です。
この記事では、エージェントとは何か、なぜこれまで紹介してきた道具（MCP・Skills・CLAUDE.md・メモリー）が「部品」として効いてくるのか、そしてどこまで任せていいのかを、やさしく見ていきます。

## AI エージェントとは — 「指示待ち」から「やり切る」へ

![AI エージェントの動き方。目標を受け取り、計画を立て、実行し、確認する。できるまでこのループを自分で繰り返す。](/diagrams/agent-loop.svg)

エージェント（agent）とは、もともと「代理で動く人」という意味の言葉です。
AI エージェントも同じで、<mark>あなたの代わりに、考えて・動いて・やり切る</mark> AI を指します。

ふつうのチャットとの違いは、はっきりしています。

- **ふつうのチャット**：一問一答。次に何をするかは、毎回あなたが指示する。
- **AI エージェント**：目標を渡すと、そこまでの手順を自分で考えて進める。

たとえば「このフォルダの資料を読んで、要点をまとめたレポートを作って」とお願いしたとします。
エージェントは、資料を一つずつ開き、必要なものを選び、要点を抜き出し、文章にまとめる——という段取りを自分で決めて、順番にこなしていきます。
あなたが一手ずつ指示しなくても、ゴールに向かって進んでくれるわけです。

## これまでの道具が「部品」になる

![これまでの道具が部品になる。MCP（手）・Skills（得意技）・CLAUDE.md（常識）・メモリー（記憶）が揃うと、自分でやり切る AI エージェントになる。](/diagrams/agent-parts.svg)

エージェントは、まったく新しい魔法ではありません。
これまでこのシリーズで紹介してきた道具が揃うと、自然と立ち上がってくる動き方です。
一つずつ、役割を当てはめてみましょう。

| 道具 | 役割 | エージェントにとっての意味 |
| --- | --- | --- |
| [MCP](/blog/mcp-server-toha/) | 外の道具を使う「手」 | ファイルやデータに実際に触れる |
| [Skills](/blog/claude-skills-toha/) | 得意技・やり方 | 決まった作業を上手にこなす |
| [CLAUDE.md](/blog/claude-md-toha/) | いつもの常識 | 毎回のお約束を外さない |
| [メモリー](/blog/claude-memory-toha/) | あなたの記憶 | 好みや前提を踏まえて動く |

<mark>「手」で触れ、「得意技」でこなし、「常識」を外さず、「記憶」で自分に合わせる。</mark>
この四つが噛み合うと、AI はただ答えるだけでなく、目標に向かって自分で動けるようになります。

だから、これまで一つずつ触ってきた道具は、どれもムダになりません。
むしろ揃うほど、エージェントとしての動きがしっかりしてきます。

## 自分で段取りを組む — 計画・実行・振り返りのループ

エージェントの中身をのぞくと、やっていることはシンプルなループです。
冒頭の図の通り、**計画を立てる → 実行する → 確認する → 次の一手**を、ゴールに着くまで自分で繰り返します。

大事なのは、<mark>「確認する」が入っていること</mark>です。
一度やって終わりではなく、うまくいったかを自分で見て、ダメなら直してもう一度試す。

分かりやすいのが、プログラムづくりの例です。
「テストが通るまで直して」とお願いすると、エージェントはコードを直し、テストを走らせ、失敗したらまた直す——を、通るまで自分で繰り返します。
人間が横について「次はこう」と言わなくても、合格というゴールに向かって進んでくれるわけです。

## 具体例 — 一つのアプリの中で完結する

いまの段階でイメージしやすいのは、<mark>一つのアプリの中で完結する仕事</mark>です。
「閉じた箱の中で、賢く動く」イメージと思ってください。

![一体の AI が、誰の指示も受けずに一人で目の前の作業に集中して取り組んでいる。閉じた箱の中で自律的にやり切るイメージ。](/img/ai-agent-toha-1.webp)

たとえば、こんなお願いができます。

- 「このフォルダの資料を全部読んで、要約レポートを1枚にまとめて」
- 「この文章の誤字を直して、読みやすく整えて、見出しもつけて」
- 「このプログラムのバグを見つけて、テストが通るまで直して」

どれも、必要な材料がその場に揃っていて、外のサービスに出かけなくても完結する仕事です。
Claude Code のような道具では、こうした作業を任せる使い方がすでに現実になっています（→ [Claude Code の使い方](/blog/claude-code-tsukaikata/)）。

まずはこの「箱の中で完結する仕事」を任せてみるのが、エージェントの入り口としてちょうどいい深さです。

## どこまで任せる？ — 自律と確認のバランス

「自分で最後までやる」と聞くと、勝手に暴走しないか心配になるかもしれません。
ここは、任せ方を選べば大丈夫です。

コツは、<mark>影響の小さい作業から任せて、様子を見ながら範囲を広げる</mark>ことです。

- はじめは、確認をはさむ設定で使う（大事な操作の前に「これで進めていい？」と聞いてくれる）
- 慣れてきたら、決まりきった作業はおまかせにする
- 消す・送るなど、取り返しがつきにくい操作は最後まで確認を残す

Claude Code には、この「どこまで自分で進めるか」を調整するしくみがあります。
くわしくは [Claude Code の自動モード](/blog/claude-code-auto-mode/) と [Claude Code の安全設定](/blog/claude-code-anzen-settei/) をどうぞ。
AI 全般の心構えは [AI を使うときの注意点](/blog/ai-anzen-chuiten/) も参考になります。

## よくある疑問

**Q. AI エージェントとふつうの AI チャットは何が違いますか？**
ふつうのチャットは一問一答で、次の一手は毎回あなたが指示します。エージェントは目標を渡すと、手順を自分で考え、実行し、確認しながら最後までやり切ります。

**Q. 使うには特別な準備がいりますか？**
身構える必要はありません。MCP・Skills・CLAUDE.md・メモリーはそれぞれ単体でも使えます。エージェントは、それらが揃ったときに立ち上がる動き方です。

**Q. 全部おまかせにして大丈夫ですか？**
大事な操作の前に確認が入る設定にしておくと安心です。影響の小さい作業から任せ、様子を見ながら範囲を広げましょう。

## まとめ

AI エージェントは、目標を渡すと自分で段取りを組み、手を動かし、最後までやり切る AI です。
「指示待ち」だった AI が、「やり切る相棒」に変わっていく——それがエージェントの正体です。

- エージェント＝計画・実行・確認のループを自分で回す AI
- MCP（手）・Skills（得意技）・CLAUDE.md（常識）・メモリー（記憶）が部品として噛み合う
- まずは一つのアプリの中で完結する仕事から任せる
- 任せる範囲は、影響の小さいところから少しずつ

まずは「このフォルダの資料をまとめて」のような、箱の中で完結するお願いから試してみてください。
AI が自分で段取りを組んで進んでいく感覚が、きっとつかめます。

そして次は、その手が「箱の外」へ伸びていきます。
複数のサービスをまたいだり、得意な AI に仕事を振ったり——という広がりの話は、[AI エージェントは外へ広がる](/blog/ai-agent-renkei/) で続けます。
