前の記事では「Claude とは何か」を見ました。この記事では、開発者に人気の
**Claude Code** を紹介します。チャットの Claude が「相談相手」だとすれば、
Claude Code は「実際に手を動かしてくれる相棒」です。

## Claude Code とは

Claude Code は、**ターミナル（コマンドライン）で動く AI エージェント**です。
ふつうのチャットとの一番の違いは、Claude 自身が

- ファイルを**読んで**内容を理解する
- コードを**書いて・直す**
- コマンドを**実行して**結果を確かめる

といった作業を、あなたのプロジェクトの中で直接おこなえる点にあります。
「このバグを直して」「テストを書いて」とお願いすると、関係するファイルを自分で探し、
変更し、必要なら動作確認まで進めてくれます。

ターミナルだけでなく、**VS Code などのエディタ拡張**や、デスクトップ・ウェブからも使えます。
まずはターミナル版が基本形です。

## 使いはじめる（おおまかな流れ）

1. Claude Code をインストールする（公式の案内に沿ってセットアップします）。
2. 作業したいプロジェクトのフォルダに移動する。
3. `claude` を起動して、やってほしいことを日本語で伝える。

あとは対話しながら進めます。Claude が「このファイルをこう変更していいですか？」と
確認してくることもあるので、内容を見て承認/修正していきます。

## 上手に付き合う 5 つのコツ

### 1. ゴールを具体的に伝える

「ログイン画面を良くして」より、「ログイン失敗時にエラーメッセージを赤字で表示して」の方が
ずっと良い結果になります。**何を・どうなったら完成か**を最初にはっきり書くのがコツです。

### 2. まず計画を立てさせる

いきなり書かせるより、「まず変更の計画だけ教えて」と一度立ち止まらせると、
方向性のズレを早い段階で正せます。納得してから実行に移すと安全です。

### 3. 変更は少しずつ、こまめに確認

大きな変更を一気に任せると、どこで何が起きたか追いにくくなります。
小さく区切って、都度確認しながら進めると失敗が減ります。

### 4. テストや動作確認をセットで頼む

「直したら実際に動かして確かめて」と伝えると、Claude が自分で結果を検証してくれます。
「直したつもり」で終わらせないための大切な一言です。

### 5. 過信しない

Claude Code はとても優秀ですが、**間違えることもあります**。
とくに消したり書き換えたりする操作は、内容を自分の目で確認してから承認しましょう。
バージョン管理（Git）を使っていれば、いつでも元に戻せるので安心です。

## どんな人に向いている？

- コードは書けるが、雑務や調べものに時間を取られている人
- 大きなコードベースの「どこを直せばいいか」を探すのが大変な人
- そして——**プログラミングにまだ自信がない初心者**

とくに最後の「初心者」にとって、Claude Code は心強い先生になります。
分からないところをその場で聞きながら、実際に動くものを作っていける。
